# A 股高影响日历订阅

每月第三个星期五为股指期货（IF/IC/IM/IH）交割日，之外还包括所有对 A 股
影响大的日子。这个仓库每周自动重新生成 `calendar.ics`，苹果日历订阅后会
定期拉取，内容一改，你的日历自动跟着变，不用重新导入。

v3（2026-10-26）：新增富时 A50 交割日；股指期货交割日事件注明同日亦为
中金所股指期权到期日（不再另设事件，因为是同一天）。

## 包含的类别

| 类别 | 规则/来源 |
| --- | --- |
| 股指期货交割日 | 每月第三个星期五；交割日前 3 天每天早上 9 点各提醒一次，交割日当天早上 9 点一次；同日亦为中金所股指期权（沪深 300 IO、上证 50 HO、中证 1000 MO）到期日 |
| 富时 A50 交割日 | 新交所富时中国 A50 指数期货，每月倒数第二个新加坡工作日，当天早上 9 点提醒 |
| CPI、PPI | 2026 年为国家统计局官方发布日程表；2027 年起官方日程未公布，按惯例推算并标注（预估） |
| PMI | 2026 年为官方表（2 月 PMI 因春节顺延至 3 月 4 日）；2027 年起按月末推算并标注（预估） |
| 国民经济运行情况 | 2026 年为官方表（GDP 季度月份 + 工业/社零/固投月度，10:00）；2027 年起按月中推算并标注（预估） |
| LPR 报价 | 每月 20 日，遇周末顺延至下周一，遇节假日顺延（以央行公告为准） |
| MLF 操作 | 每月 25 日前后，遇周末/节假日顺延（以央行公告为准） |
| 财报季 | 年报预告 1/31、年报+一季报 4/30、半年报预告 7/15、半年报 8/31、三季报预告 10/15、三季报 10/31，遇周末提前至前一个工作日 |
| MSCI 季度调整 | 季末最后一个交易日收盘后生效（2026 年 2/5/8 月为官方公告日，11 月起按惯例） |
| 富时罗素季度调整 | 季月第三个周五后的周一开盘前生效（2026 年 9 月为官方公告日，其余按惯例） |
| 美联储议息 | 决议公布日（北京时间），即美国议息会议次日凌晨公布后的第一个 A 股交易日上午 |
| ETF 期权到期 | 每月第四个星期三 |
| 国债期货交割 | 季月（3/6/9/12 月）第二个星期五 |
| 全国两会 | 2026 年政协 3 月 4 日、人大 3 月 5 日；2027 年起日期公布后更新 |
| A 股休市 | 2026 年国务院放假安排对应的假期 block；2027 年放假安排公布后更新 |

## 部署（只需要做一次）

### 1. 新建仓库

GitHub 上新建一个仓库，名字随便（比如 `futures-calendar`），
**必须选 Public**（免费版 GitHub Pages 只支持公开仓库）。
日历里只有公开的市场日程，不含任何隐私内容，公开没有关系。

### 2. 把文件放进去

方法 A（会用 git）：把这个压缩包解压，把里面的文件全部拷进仓库，提交推送。

方法 B（不会 git，全程网页操作）：
- 仓库页面点 Add file → Upload files，上传 `generate_calendar.py`、`calendar.ics`、`README.md`、`.nojekyll`。
- 再点 Add file → Create new file，文件名一栏直接输入
  `.github/workflows/update.yml`，把 `update.yml` 的内容粘贴进去，提交。
  （文件名里带斜杠，GitHub 会自动建文件夹。）

### 3. 开启 Pages

仓库 Settings → Pages → Build and deployment：
- Source 选 Deploy from a branch
- Branch 选 main，文件夹选 /(root)，保存。

等一两分钟，打开下面的链接，能下载到 `calendar.ics` 就说明成功了：

```
https://你的GitHub用户名.github.io/仓库名/calendar.ics
```

### 4. iPhone 上订阅

设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历，
粘贴上面那个链接，点下一步 → 存储。

## 更新与顺延

市场日程变动没有实时推送接口，所以顺延和官方日程都是手动维护的，
但维护一次，所有订阅的人自动同步：

1. 每年官方日程公布后（统计局发布日程表、国务院放假安排、两会日期、
   MSCI/富时罗素公告、美联储日历），把受影响的日期写进
   `generate_calendar.py` 对应的数据表（表头有注释说明每个表的来源）。
2. 提交后 Action 立刻重新生成并发布；每周一的定时任务也会兜底刷新。
3. 股指期货交割日遇假日顺延：改 `FUTURES_OVERRIDES` 里的一行即可。

- 2027 年 9 月的富时罗素调整生效日按惯例为 9 月 20 日（周一），
  以富时罗素公告为准。
- 富时 A50 交割日按周一至周五推算，未计入新加坡假期；若某月月末
  恰逢新加坡假期，实际交割日可能提前一天，以新交所公告为准
  （2027 年 10 月屠妖节日期待确认，该月日期可能因此变动一天）。

## 核实说明（2026-10-26）

- 中金所股指期权规则经中金所品种页、《股指期权合约交易细则》
  第 12 条、交割通知三处印证：最后交易日为到期月份第三个星期五，
  遇假日顺延至下一交易日，到期日同最后交易日，现金交割。
  因此与股指期货交割日是同一天，不另设事件。
  品种代码注意：中金所只有三只股指期权（IO/HO/MO），
  IC 是中证 500 股指期货，IM 是中证 1000 股指期货。
- 富时 A50 交割规则（每月倒数第二个新加坡工作日）经新交所
  合约月份到期数据交叉验证：2026 年 4 月 29 日、6 月 29 日、
  11 月 27 日、2027 年 9 月 29 日均符合该规则。
- 网上流传的“2026 年 A 股交割日”表格不作为来源：
  其中股指期权一列与中金所规则不符，6 月股指期货交割日
  误写在端午假期（市场休市日）。

## 没做进日历的

- 社融/金融数据：央行每月中旬公布，无固定日期。
- 政治局会议、中央经济工作会议：无提前公布的固定日期，当天才知道。
- 个股解禁、除权除息、打新：个股层面每天都有，不适合通用日历。

## 文件说明

- `generate_calendar.py`：生成器，只用 Python 标准库，窗口为本月起往后 26 个月。
- `calendar.ics`：生成的日历文件，事件 UID 按类别+日期固定，重新生成不会重复。
- `.github/workflows/update.yml`：每周一自动重新生成并提交的任务。
- `.nojekyll`：告诉 Pages 不要用 Jekyll 处理，直接原样发布。
